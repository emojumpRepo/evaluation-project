## Context

本项目是一个基于 Spring Boot 的宝宝测评系统，目前包含基础的宝宝信息管理、测评功能以及测评结果生成功能。系统采用微服务架构，使用 MyBatis Plus 作为 ORM 框架，支持多租户机制。

现有技术栈：
- 后端：Spring Boot + MyBatis Plus + MySQL
- 文件存储：已集成文件存储服务，支持本地存储和云存储
- PDF生成：已有基于 Apache PDFBox 的测评报告生成器
- 权限控制：基于 Spring Security 的权限管理

## Goals / Non-Goals

- **Goals**:
  - 提供完整的文件上传和管理功能
  - 支持灵活的测评报告导出方式
  - 确保文件安全性和访问权限控制
  - 保持与现有系统的兼容性
  - 提供良好的用户体验和管理效率

- **Non-Goals**:
  - 不重构现有的测评系统架构
  - 不改变现有的用户权限体系
  - 不支持在线文件编辑功能
  - 不实现文件版本控制

## Decisions

### 1. 数据存储设计

**Decision**: 创建独立的文件关联表 `baby_assessment_file` 来管理上传文件与业务实体的关系。

**Rationale**:
- 使用关联表而非在现有表中添加文件字段，支持一对多关系（一个宝宝或测评结果可以有多个文件）
- 便于后续扩展和维护
- 符合数据库设计的第三范式

**Alternatives considered**:
- 在现有表中添加 JSON 字段存储文件信息：查询性能较差，不易索引
- 直接在文件表中添加业务关联：违反单一职责原则

### 2. 文件存储策略

**Decision**: 复用现有的文件存储服务 (`FileService`)，不重新实现文件上传和存储逻辑。

**Rationale**:
- 现有文件存储服务已经支持多种存储后端（本地、阿里云OSS、七牛云等）
- 避免重复开发，减少维护成本
- 保持系统架构的一致性

### 3. 导出功能设计

**Decision**: 采用分层导出策略，支持多种导出方式。

**Rationale**:
- 满足不同用户的使用场景（只需要报告、只需要文件、完整包）
- 减少不必要的数据传输
- 提供更好的用户体验

**Technical approach**:
- PDF报告：复用现有的 `AssessmentResultPdfGenerator`
- 文件下载：直接使用文件存储服务
- ZIP打包：使用 Java 标准库的 `java.util.zip`

### 4. 权限控制设计

**Decision**: 基于现有的权限体系，增加附件访问权限控制。

**Rationale**:
- 用户只能下载自己宝宝相关的附件
- 管理员可以上传、管理和查看所有用户的附件
- 延续现有的权限控制模式
- 管理后台上传需要管理员权限验证

## Risks / Trade-offs

### 1. 文件存储空间风险
- **Risk**: 管理员上传大量附件可能导致存储空间不足
- **Mitigation**: 设置文件大小限制、文件类型限制，定期清理无用附件

### 2. 性能影响
- **Risk**: 大文件上传和下载可能影响系统性能
- **Mitigation**: 使用异步处理、分块上传、CDN加速

### 3. 安全性风险
- **Risk**: 管理员误传恶意文件可能带来安全风险
- **Mitigation**: 文件类型检查、病毒扫描、管理员权限控制、操作日志记录

### 4. 数据一致性
- **Trade-off**: 文件存储与数据库记录的一致性维护
- **Mitigation**: 使用事务管理、文件删除时的级联操作

## Migration Plan

### Phase 1: 数据库变更
1. 创建 `baby_assessment_file` 表
2. 添加必要的索引和约束
3. 进行数据迁移验证

### Phase 2: 后端服务开发
1. 实现文件管理服务层
2. 创建相关的 Controller 和 VO
3. 集成现有的文件存储服务

### Phase 3: 导出功能开发
1. 扩展现有的PDF生成器
2. 实现ZIP打包功能
3. 添加导出接口

### Phase 4: 前端集成
1. 更新小程序端页面
2. 更新管理后台页面
3. 进行端到端测试

### Phase 5: 部署和监控
1. 部署到测试环境进行验证
2. 监控系统性能和存储使用情况
3. 逐步部署到生产环境

## Open Questions

1. **文件存储配额**: 是否需要对用户的文件存储空间进行配额限制？
2. **文件保留策略**: 用户删除宝宝信息时，相关文件应该如何处理？
3. **并发控制**: 多个用户同时上传文件时，如何处理并发冲突？
4. **文件分享**: 是否需要支持文件分享功能给其他用户查看？
5. **离线模式**: 是否需要支持离线模式下的文件缓存机制？
